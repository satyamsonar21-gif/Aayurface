---

### 1. Evidence Hierarchy Key

* **Level 1:** Actual runtime / test execution evidence (terminal commands, test passes/fails).
* **Level 2:** Actual repository source code, lockfiles, and configuration files.
* **Level 3:** Database schemas, Supabase project configuration, and service inspection.
* **Level 4:** Existing audited engineering documentation (`docs/engineering/audit/`).
* **Level 5:** Explicit project owner / product management decisions (`D:\aayurface prd.txt`).
* **Level 6:** Scientific research and reference literature (`D:\AayurFace Research.pdf`).
* **Level 7:** Engineering inferences and deductions (must be qualified).
* **Level 8:** Assumptions (must be tracked and eliminated).
