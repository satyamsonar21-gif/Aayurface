# ADR-FE-012: 7-Pillar AI Explainability UI Architecture

**Status:** ACCEPTED  
**Date:** 2026-09-03  
**Context:**  
Black-box AI recommendations alienate users and prevent scrutiny by wellness practitioners. Users need to understand why a recommendation was made without exposing internal model chain-of-thought.

**Decision:**  
The UI implements a structured **7-Pillar Explainability Accordion** answering: What was observed, What influenced it, Which modality led, Confidence level, Ayurvedic meaning, Negative medical boundaries, and Classical treatise citations.

**Consequences:**  
* Demystifies AI reasoning while strictly grounding advice in classical Sanskrit literature.
* Enforces non-diagnostic boundaries on every assessment.

**Truth Status:** `TARGET ARCHITECTURE (REQUIRES IMPLEMENTATION)`
