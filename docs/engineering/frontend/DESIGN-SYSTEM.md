## 1. The Tri-Pillar Aesthetic Ratio

AayurFace is visually engineered around a locked **50 / 30 / 20 Aesthetic Formulation**:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       AAYURFACE TRI-PILLAR RATIO                            │
├──────────────────────────────────────┬──────────────────────────────────────┤
│ 50% Luxury & Refinement              │ • Generous, calm whitespace          │
│                                      │ • Restrained, elegant proportions    │
│                                      │ • Editorial serif typography         │
├──────────────────────────────────────┼──────────────────────────────────────┤
│ 30% Ayurvedic Natural Character      │ • Botanical greens & warm ivory      │
│                                      │ • Muted herbal & antique gold accents│
│                                      │ • Grounded Sanskrit/classical terms  │
├──────────────────────────────────────┼──────────────────────────────────────┤
│ 20% Editorial Modern Technology      │ • Clean, crisp data visualizations   │
│                                      │ • Precise, transparent uncertainty   │
│                                      │ • High-performance responsive UI     │
└──────────────────────────────────────┴──────────────────────────────────────┘
```

## 2. Visual Anti-Patterns (Explicitly Prohibited Styles)

To prevent the application from resembling generic AI templates or clinical hospital portals:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                          PROHIBITED VISUAL STYLES                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ ❌ NO Dark Cyberpunk / Neon Themes (Application is strictly LIGHT THEME)    │
│ ❌ NO Multi-Color Neon Gradients (Purple/Cyan AI gradients are barred)      │
│ ❌ NO Excessive Glassmorphism / Frosted Blurs that degrade readability      │
│ ❌ NO Exaggerated 3D Floating Elements or Gimmicky Parallax                 │
│ ❌ NO Clinical Hospital Aesthetic (Sterile cold blue / white)               │
│ ❌ NO "AI Magic" Gimmicks (Wand icons, generic glitter sparks)              │
│ ❌ NO Childish Gamification (Cartoony badges, confetti explosions)          │
└─────────────────────────────────────────────────────────────────────────────┘
```
