### 1. Threat Modeling Methodology

The threat model applies the **STRIDE** methodology across all fourteen architectural tiers and trust boundaries of AayurFace:
* **S — Spoofing Identity:** Impersonating a legitimate user, administrator, or internal service.
* **T — Tampering with Data:** Modifying records, algorithms, prompt context, or network payloads.
* **R — Repudiation:** Denying that an action, consent grant, or transaction occurred without proof.
* **I — Information Disclosure:** Exposing sensitive biometrics, health inputs, tokens, or system secrets.
* **D — Denial of Service:** Depleting cloud compute, AI inference budgets, or storage availability.
* **E — Elevation of Privilege:** Gaining unauthorized user, admin, or service-role permissions.

Risk is quantified as $\text{Risk} = \text{Likelihood} \times \text{Impact}$ using standard 5-point ordinal scales:
* **Impact:** Minimal (1), Low (2), Moderate (3), High (4), Critical (5)
* **Likelihood:** Rare (1), Unlikely (2), Possible (3), Likely (4), Frequent (5)
* **Risk Score:** Low (1–5), Medium (6–11), High (12–19), Critical (20–25)

### 3. Top Critical Security Threats (Ranked by Risk Score)

1. **TH-17: Public S3 Bucket Exposure (Risk Score: 20 — Critical):** Public read permissions on `facial-captures/` would allow automated mass scraping of high-resolution biometric facial images. *(Mitigation: Zero public reads; signed access only).*
2. **TH-18: BOLA / IDOR Cross-Tenant Data Leakage (Risk Score: 20 — Critical):** Attackers manipulating UUIDs in `/api/v1/analysis/{id}` to view other users' sensitive Ayurvedic assessments. *(Mitigation: Server-side identity extraction from JWT + PostgreSQL kernel RLS).*
3. **TH-01: Client-Supplied Identity Spoofing (Risk Score: 20 — Critical):** Insecure prototype endpoints accepting `request.body.userId` without token verification. *(Mitigation: Strict server derivation from verified JWT `auth.uid()` claim).*
4. **TH-49: AI Diagnostic & Prescriptive Hallucination (Risk Score: 20 — Critical):** Generative model emitting clinical disease diagnoses or prescription drugs. *(Mitigation: Post-inference deterministic safety filter + fail-closed Zod schema).*
5. **TH-25: Denial-of-Wallet AI Inference Depletion (Risk Score: 16 — High):** Malicious actors automating thousands of analyses to exhaust company OpenAI credits. *(Mitigation: Sliding window rate limiting: proposed 5 analyses/user/hour).*
6. **TH-35: Wildcard CORS Exploitation (Risk Score: 16 — High):** Discovered wildcard `*` CORS in existing prototype Edge Functions. *(Mitigation: Strict origin whitelisting in production).*
7. **TH-09: Direct Prompt Injection / Jailbreaking (Risk Score: 16 — High):** Adversarial instructions in skin concerns overriding system disclaimers. *(Mitigation: Delimiter fencing + input length limits).*
