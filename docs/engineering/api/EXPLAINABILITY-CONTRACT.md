## 1. Explainability Core Questions

Every analysis generated by AayurFace must answer seven transparent questions:
1. **What was observed?** (Extracted physical observables: redness, texture, moisture).
2. **What influenced the result?** (Modality contribution weights).
3. **Which modality contributed?** (Visual vs Questionnaire vs Lifestyle).
4. **What evidence supports it?** (Retrieved classical verses and Guna heuristics).
5. **What confidence exists?** (Calibrated confidence score and harmonic agreement index).
6. **What limitations exist?** (Lighting, image resolution, self-report subjectivity).
7. **What does the result NOT mean?** (Explicit negative medical boundaries).

## 2. Explainability Object Contract

```typescript
export const ExplainabilityPayloadSchema = z.object({
  analysisId: z.string().uuid(),
  observedSignals: z.array(z.object({
    modality: z.enum(['VISUAL', 'QUESTIONNAIRE', 'LIFESTYLE']),
    signalDescription: z.string(),
    signalValue: z.string(),
    doshicImplication: z.enum(['VATA', 'PITTA', 'KAPHA', 'BALANCED'])
  })).min(3),
  modalityContributionWeights: z.object({
    visualWeightPercentage: z.number(),
    questionnaireWeightPercentage: z.number(),
    lifestyleWeightPercentage: z.number()
  }),
  harmonicAgreementIndex: z.number().min(0.0).max(1.0),
  supportingClassicalVerseIds: z.array(z.string().uuid()),
  confidenceScore: z.number().min(0.0).max(100.0),
  scientificLimitations: z.array(z.string()).min(1),
  negativeMedicalBoundaries: z.array(z.string()).min(1)
}).strict();
```
